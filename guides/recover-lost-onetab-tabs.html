How to recover lost OneTab tabs

Updated 2026-10-12 · Applies to Chrome, Edge, Brave and Firefox

Users have reported OneTab lists disappearing after a reboot or an update. OneTab keeps its list inside the browser's storage for the extension, so when that storage is lost or reset, the list goes with it. There is no guaranteed fix, but these steps give you the best chance, in order of risk.

1. Stop and don't make it worse

  • Don't uninstall or reinstall OneTab. Removing an extension deletes its stored data.
  • Don't clear browsing data or run "cleaner" apps until you're done.
  • If you can, close the browser and copy your whole browser profile folder somewhere safe before trying anything else. In Chrome/Edge/Brave, its path is shown as Profile Path at chrome://version; in Firefox, at about:profiles.

2. Look for an export you already have

OneTab's Export / Import URLs page gives you your list as text (URL | Title per line). Search your notes, documents and email for a pasted copy: search for " | " together with a site you remember.

3. Rebuild from browser history

Tabs you sent to OneTab were usually visited first, so they're in your history unless you cleared it. Open chrome://history (or Library → History in Firefox), go to the dates you collected them, and search by site or keyword.

4. Firefox only: session backups

Firefox keeps recent session files in the sessionstore-backups folder of your profile (recovery.jsonlz4, previous.jsonlz4, upgrade.jsonlz4-…). They contain the tabs that were open at those times — useful if you sent tabs to OneTab recently. They're compressed; Tab Session Manager can import them (Settings → Import), which lets you browse the tabs.

5. Restore an older copy of the profile

If you have system backups (Windows File History / "Previous versions", macOS Time Machine), you can restore the profile folder from before the loss:

  1. Close the browser completely.
  2. Keep the copy you made in step 1.
  3. Restore the older version of the entire profile folder (not just one subfolder: we couldn't verify the exact subfolder OneTab uses in 2026, and extension data spans several).
  4. Open the browser and check OneTab. Export immediately if your list is back.

Restoring a profile also rolls back bookmarks, passwords and history to that date. If that matters, restore it into a separate folder and open it as a new profile instead.

6. Ask OneTab's developer

Contact OneTab through its official site with your browser version and what happened.
