Migrate to Tab Vault

Import is free in every plan and never overwrites anything: each imported list becomes a new collection.

From OneTab

  1. Open OneTab and click Export / Import URLs.
  2. Select all the text in the export box and copy it.
  3. Open Tab Vault → Import / Export → paste into the text box.
  4. Check the preview ("OneTab: N collections, M tabs") and click Import.

Each block separated by a blank line becomes its own collection. Titles containing " | " are kept intact.

From Session Buddy

  1. In Session Buddy, open the menu → Export → choose JSON and save the file.
  2. Tab Vault → Import / Export → Choose a file → pick it.
  3. Check the preview and click Import. Both current (collections) and older (sessions) backup formats are supported.

From Tab Session Manager

  1. In Tab Session Manager's settings, find the export/backup option and save your sessions as a .json file.
  2. Tab Vault → Import / Export → Choose a file.
  3. Each session becomes a collection, with tabs in their original order.

After importing

  • Keep the original export file as an extra backup.
  • Turn on automatic export (Pro) or download a JSON export from time to time.
  • If a file isn't recognized, write to support — attaching a sample (with private URLs removed) helps a lot.
