I lost tabs — what now?

  1. Don't uninstall Tab Vault. Uninstalling deletes its storage.
  2. Open Tab Vault → Timeline and restore the latest snapshot that has your tabs.
  3. If you see a red Possible data loss detected banner, click Download last good copy (Free) or Restore missing collections (Pro).
  4. If automatic export was on, import the latest file from Downloads/Tab Vault Backups/ via Import / Export.

Pro says it can't validate

Pro works offline for 30 days after the last successful check. Go online and click Re-check now in Pro & license. Your data is never deleted when Pro lapses.
